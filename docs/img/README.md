# Illustrations

The six WebP files here are generated illustrations, not photographs. They are visual framing only; the real screenshots below them are the evidence. Each caption names the scene.

| File | Scene | Caption | Source |
|---|---|---|---|
| `01-hero.webp` | Three-quarter laptop, lid open, glowing screen | Illustration — lid open, screen glowing, three-quarter view | HTML/CSS in `build/render-illustrations.js`, rendered 2x with Playwright, WebP q85 |
| `02-usb-install.webp` | USB stick beside the laptop | Illustration — USB installer beside the machine | Same renderer |
| `03-audio.webp` | Speaker grille detail | Illustration — speaker grille detail | Same renderer |
| `04-wireless.webp` | Two wireless halos | Illustration — Wi-Fi and Bluetooth halos | Same renderer |
| `05-touchpad.webp` | Touchpad with gesture trail | Illustration — touchpad surface with gesture trail | Same renderer |
| `06-touchscreen-section.webp` | Screen with faint panic stack | Illustration — screen with panic stack faintly overlaid | Same renderer |

The renderer source is not shipped in the repository because it is part of the build workspace. The captions below keep the word “Illustration” so these files cannot be read as hardware proof.

**Note:** The wallpaper‑only captured screenshots (01‑desktop … 10‑panic) have been removed because they contained no actionable data.
